# 멜버니의 걸음마 👣

멜버니(2026.09.15 출생 예정)의 성장 앨범 + 육아기록 PWA — 우리 가족만의 비밀 공간.

## 🔗 링크

- **앱**: https://jycho7254-commits.github.io/melbourny-walks/
- **가족 비밀번호**: `260915`

## ✨ 기능 (v10, 2026-09-18)

| 탭 | 기능 |
|---|---|
| 📖 앨범 | 사진 타일 그리드 (3열) + **기록자 필터(모두/아빠/엄마/가족 관계 동적 생성)** + 날짜 팝업(당일 사진+일기) |
| 🍼 수유텀 | 쑥쑥찰칵 벤치마킹 — 원형 카테고리 버튼 7종(모유/분유/이유식/소변/대변/수면/약), 상세 기록 시트(ml 스테퍼+퀵버튼, 모유 좌/우 분 스테퍼+합산), 시간 직접 설정("지금!"), 세로 타임라인(날짜 헤더+D+일일요약+오전/오후 시간칩+`9.18 D+3` 날짜 병기), 최근 상태 스트립 |
| 📊 통계 | **[오늘]** 24시간 시계형 원형 차트 + 하루의 흐름 문장 + **리듬 요약 2×2 카드**(수면/수유·식사: 총ml·총분·간격/배변: 소변·대변 분리/약) · **[주간]** 7일 요약/수유 간격(평균·최단·최장)/시간대 히트맵/14일 추이(D+day 병기) |
| 📸 사진 | 사진/동영상 업로드 (1000px/78% 자동 압축 — 실측 92% 감소, 동영상 20MB) + 메모 + **기록자 자동 태그** |
| ✏️ 일기 | 짧은 육아 일기 + 기록자 태그 |
| 🗓️ 달력 | 포토캘린더 — 같은 날 여러 장 **+N 뱃지**, 클릭 시 전부 보기, 출생일 💗 |

### 👨‍👩‍👧 가족 관계 (기기별 1회 설정)

`아빠 / 엄마 / 할아버지 / 할머니 / 외할아버지 / 외할머니 / 고모 / 삼촌 / 가족` (9종)
→ 해당 기기에서 올린 사진·일기·수유텀에 자동 태그 (타일 배지/칩/필터에 반영)

### 🛡️ 안전 설계

- 수유텀: 서버 장애 시에도 로컬 저장 → 기록 절대 유실 없음
- 앨범: 서버 장애 시 로컬 캐시 폴백 → 빈 앨범 방지
- toast는 pointer-events:none — 팝업 클릭을 절대 가로채지 않음

## 🗄️ DB

**Supabase 전용 프로젝트** `csenbounuattwcivyuho` (가족앱 전용 — 아린 앱과 공유, 500MB 독립 풀)

| 테이블 | 용도 |
|---|---|
| mel_photos | 사진/동영상 (base64, photo_date/memo — memo 앞에 `관계|` 프리픽스) |
| mel_diary | 일기 (text — 동일 프리픽스) |
| mel_care | 수유텀 (kind/detail/memo/by/created_at — 시간 소급 설정 지원) |

- RLS: anon 전체 허용 (사이트 자체가 비밀번호 게이트로 보호)
- 용량: 사진 압축 후 하루 10장도 연 255MB — 무료 0원 / 매월 1일 감시 크론(storage_watch) 보고

## 🏗️ 구조

```
melbourny-walks/

```

## 📱 설치 (가족용)

- **안드로이드**: 크롬으로 열기 → ⋮ → 홈 화면에 추가
- **아이폰**: 사파리로 열기 → 공유⬆️ → 홈 화면에 추가
