# 멜버니의 걸음마 👣

멜버니(2026.09.15 출생 예정)의 성장 앨범 PWA — 우리 가족만의 비밀 공간.

## 🔗 링크

- **앱**: https://jycho7254-commits.github.io/melbourny-walks/
- **가족 비밀번호**: `260915`

## ✨ 기능

| 탭 | 기능 |
|---|---|
| 📖 앨범 | 사진/동영상 타임라인 (날짜+메모+D+day 태그, 날짜 팝업) |
| 📸 기록 | 사진/동영상 업로드 (자동 리사이즈, 동영상 30MB) + 메모 |
| ✏️ 일기 | 사진 없는 짧은 육아 기록 |
| 🗓️ 달력 | 사진 올린 날 썸네일, 출생일 💗 마킹 (2026.09.15) |

- 👥 **부부 실시간 공유** — 서버 저장, 양방향 동기화
- 🔗 **카톡 공유** — Web Share API (사진 파일 그대로 전송)
- 📱 **PWA** — 홈 화면 설치 시 앱처럼 실행 (주소창 없음)
- 🗑️ 삭제 — 카드/일기별, 서버+로컬 동시 (confirm 이중 확인)
- 👣 **D+day** — 1분 자동 갱신, 출생 후 "멜버니랑 ○일" 전환 (로컬 자정 기준 — UTC 오차 없음)

## 📦 용량 운영

- 사진(약 200KB/장) 하루 5장 → 연 360MB, **무료 0원**
- 동영상이 변수 — 긴 영상 자주 올리면 80% 도달 시 월 1회 감시 크론이 보고 (storage_watch)
- 한도 임박 시: 업로드 압축 강화(10MB) 또는 Pro($25/월) 또는 Storage 버킷(1GB 무료) 전환
